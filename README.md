## Netflix Power BI Dashboard
This Power BI dashboard analyzes Netflix’s global catalog to uncover trends in content distribution, genre popularity, and release patterns. 

### Overview 
The dashboard explores Netflix's catalog to uncover insights about content trends, genre popularity, release patterns, and geographic distribution. It demonstrates my ability to clean, model, and visualize data to support business decision-making.

### Key Insights
- Genre Distribution: Identifies which genres dominate Netflix's offerings
- Release Year Trends: Shows how content production has evolved over time
- Content Type Breakdown: Compares movies vs. TV shows
- Country Availability: Highlights geographic distribution of titles
- Ratings & Maturity Levels: Examines viewer suitability and content classification
